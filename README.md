# Extensões arquivadas

> [!WARNING]
> Os projetos deste repositório estão descontinuados. Eles são preservados apenas como registro histórico e não recebem correções, suporte ou atualizações. Não são recomendados para instalação.

Coleção de userscripts antigos, sem relação com as extensões jurídicas da organização CodaCoisa.

| Pasta | Finalidade | Situação |
| --- | --- | --- |
| [`opensubtitles-brazilian`](opensubtitles-brazilian/) | Prioriza legendas em português brasileiro no OpenSubtitles. | Descontinuada. |
| [`psa-telegram`](psa-telegram/) | Abre links do Telegram a partir do PSA. | Descontinuada. |
| [`script-manager`](script-manager/) | Gerencia userscripts diretamente em uma página. | Descontinuada. |

## Histórico

Cada pasta conserva o código e o histórico completo do respectivo repositório original, incluindo autores, datas e mensagens dos commits.

Os arquivos podem depender de comportamentos antigos dos sites, dos navegadores, dos gerenciadores de userscripts ou de serviços externos.
